# מה מקור השם?

יישומון אטימולוגי רב־לשוני שמטרתו להסביר את המקור, המשמעות וההיסטוריה של שמות בשפה פשוטה וברורה.

## גרסה 0.1

הגרסה הראשונה כוללת:

- ממשק מלא בעברית ובכיוון RTL.
- חיפוש שמות, מקומות ומילים בכל שפה.
- חיפוש חי ב־Wikidata, ויקיפדיה וויקימילון.
- מסך תוצאה עם הסבר פשוט, מקור השם, מסלול אטימולוגי, רמת ודאות ומקורות.
- עיקרון מחקרי מרכזי: אם אין מידע מספק, היישומון אומר זאת במפורש ולא ממציא אטימולוגיה.
- עיצוב מותאם למחשב ולטלפון ונגישות בסיסית.

## השלבים הבאים

1. שיפור מנגנון זיהוי האטימולוגיה מתוך Wiktionary.
2. הפרדה בין עובדות, השערות ומחלוקות מחקריות.
3. בניית עץ אטימולוגי אמיתי וציר זמן של צורות היסטוריות.
4. הוספת מקורות לשוניים ואקדמיים חינמיים נוספים.
5. שיפור חיפוש רב־לשוני, תעתיקים ושמות חלופיים.

הפרויקט מפורסם תחת רישיון MIT. מידע שמגיע ממקורות Wikimedia כפוף לרישיונות המקור הרלוונטיים.
